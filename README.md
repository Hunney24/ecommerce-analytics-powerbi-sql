
# E-Commerce Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end data analytics workflow using MySQL, SQL, and Power BI.

The objective was to analyze e-commerce sales, customer behavior, marketing performance, product performance, and conversion funnel metrics to generate actionable business insights.

---

## Tech Stack

* MySQL
* SQL
* Power BI
* DAX
* GitHub

---

## Dashboard Pages

### 1. Executive Summary Dashboard

* Total Revenue
* Total Orders
* Average Order Value
* Total Customers
* Revenue by Source
* Revenue by Country

### 2. Marketing Performance Dashboard

* Revenue by Acquisition Channel
* Orders by Acquisition Channel
* Revenue Contribution by Channel
* Country-Level Filtering

### 3. Product Performance Dashboard

* Revenue by Category
* Customer Engagement by Category
* Customer Satisfaction Ratings
* Product Performance Insights

### 4. Conversion Funnel Dashboard

* Page Views
* Add to Cart
* Checkout
* Purchases
* Funnel Conversion Rates
* Funnel Drop-Off Analysis

---

## Key Insights

* Organic traffic generated the highest revenue and order volume.
* Home & Kitchen was the highest revenue-generating category.
* Books received the highest engagement despite generating lower revenue.
* Significant customer drop-off occurred between Add to Cart and Checkout stages.
* Checkout-to-Purchase conversion remained strong at over 74%.
